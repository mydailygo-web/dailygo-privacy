# DAILYGO Privacy Policy

This public repository contains the public-facing DAILYGO privacy policy.

- Website entry point: `index.html`
- Custom domain: `dailygo.app`
- Support and privacy requests: `mydailygo@gmail.com`

The application source remains in the separate private `plan-manage-grow` repository.

**Publication is not a confirmation that every operational statement in the policy has been audited.** Before submitting the URL to Google Play, verify production data flows, SDKs and service providers, retention, and the actual account-deletion process against the live app.
